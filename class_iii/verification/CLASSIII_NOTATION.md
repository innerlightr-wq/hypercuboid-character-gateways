# Class III Sequel — Notation Reference

Fixed notation for the sequel manuscript, chosen to match the existing
Classes I/II manuscript's conventions wherever they carry over directly
(same `χ`, same `p`, same general character-sum style), and introducing
new symbols only where Class III genuinely needs them.

## Base objects

- `p` — an odd prime (the domain of every result in this paper; `p=2` is
  excluded throughout and is the surface's only bad prime).
- `χ` — the quadratic (Legendre) character mod `p`, `χ(0)=0`.
- `F_p` — the finite field of order `p`.

## The Class III sum

- `P_III(x0,x1,x2) = x0 x1 x2 (x0+x2)(x1+x2)(x0+x1+x2)` — the degree-6
  defining polynomial (inherited unchanged from the parent hypercuboid
  classification; **not redefined** in the sequel, only cited).
- `Σ_III(p) = Σ_{x∈F_p^3} χ(P_III(x))` — the raw three-variable Class III
  character sum.
- `T(p) = Σ_{x,t∈F_p} χ(x\,t(t+1)(x+t)(x+t+1))` — the reduced two-variable
  sum (the paper's real object of study after §1).

## The K3 surface

- `X_III` — the (unique, up to the identifications made in this paper)
  singular K3 surface constructed from `T(p)`.
- `V_III : Y² = X(X+1)T(T+1)(X+T+1)` — the defining affine model over the
  `T`-line (note: `T` plays the role of the elliptic fibration's *base*
  coordinate; `X,Y` are the fiber coordinates — this double use of
  variable names, `T` as both a prime-independent formal base coordinate
  and (informally, in Classes I/II's own convention) a stand-in the reader
  might expect for "the prime," is worth one clarifying sentence in the
  paper's §1, since Class III's base curve really is named `T` throughout
  the exploration notes and it is cleanest to keep that name rather than
  relabel to `t` or `s` at this late stage).
- `a2(T)=T(T+1)(T+2)`, `a4(T)=T²(T+1)³` — Weierstrass coefficients of the
  minimal model `Y²=X³+a2(T)X²+a4(T)X`.
- `c4(T), c6(T), Δ(T)` — the standard Weierstrass invariants; `Δ =
  16T^8(T+1)^8`.
- Bad fibers: `T=0`, `T=-1`, `T=∞`, each of Kodaira type `I2*`.

## Lattice-theoretic objects

- `NS(X_III)` — the Néron–Severi lattice, rank 20 (singular K3).
- `Triv(X_III) = U + D6 + D6 + D6` — the trivial lattice (Shioda–Tate),
  `U` the hyperbolic plane (zero section + fiber class), each `D6`
  generated by the 6 non-identity components of one `I2*` fiber.
- `T(X_III)` — the transcendental lattice, rank 2 (`22-20`).
- `MW(X_III)` — the Mordell–Weil group; `MW_tors ≅ (Z/2)²`, `MW`-rank `0`.
- `O` — the zero section. `P1=(0,0)`, `P2=(-T(T+1),0)`, `P3=(-T(T+1)²,0)`
  — the three nonzero `Q(T)`-rational 2-torsion sections.

## The affine-`D6` fiber graph (central to §4)

- `I2*` fiber components: 7 total per fiber. Four of multiplicity 1
  ("legs," in two pairs, one pair per end), three of multiplicity 2
  ("spine," a path connecting the two ends).
- Legs written `L1,L2` (one end) and `L3,L4` (other end); spine written
  `S1–S2–S3` (path, `S1` adjacent to `L1,L2`, `S3` adjacent to `L3,L4`).

## The modular form

- `f_16` — LMFDB label `16.3.c.a`, the weight-3, level-16 newform with CM
  by `Q(i)`, equal to Ahlgren–Ono–Penniston's `A(z) = η^6(4z)`.
- `a_p(f_16)` — its `p`-th Hecke eigenvalue (Fourier coefficient).
- `χ(-1), χ(2), χ(-2)` — the three nontrivial quadratic characters in the
  twist candidate set `{1,χ(-1),χ(2),χ(-2)}`.

## Comparison objects (Classes I/II, cited not redefined)

- `S(p)` — the Classes I/II two-variable reduced sum (defined in the
  existing manuscript; only referenced here, never redefined).
- `g = 8.3.d.a` — the Classes I/II governing newform, CM by `Q(√-2)`,
  level 8 (cited from the existing manuscript for the comparison table in
  §8 only).

## Style notes

- Follow the existing manuscript's convention: `χ(-1)` written out, not
  abbreviated `χ_{-1}` in running text (reserve the subscript form only
  for Dirichlet-character/Nebentypus notation when citing LMFDB data).
- Use `T` consistently for the base coordinate throughout (never switch to
  `t` mid-paper); use `p` exclusively for the prime.
- Status labels (if retained in any appendix) follow the project's
  established taxonomy: PROVED — SELF-CONTAINED / PROVED — LITERATURE /
  FINITE THEOREM-BASED VERIFICATION — but the **main text** should read as
  a normal theorem/proof paper and should not carry these labels; they
  belong only in the appendix's audit-trail material, if included at all
  (see `CLASSIII_APPENDIX_PLAN.md`).
